## Sobre mim

Construo **APIs Java/Spring Boot pensadas para produção**: regras de negócio testadas, mensageria, segurança e observabilidade. Também entrego **apps Android nativos** em Kotlin/Compose e ferramentas desktop. Curso **Análise e Desenvolvimento de Sistemas na FIAP** e tenho base em **Design Digital**, o que me faz cuidar da experiência de quem usa o que eu construo.

**O que levo para o time**

- ✅ Código com testes (JUnit, Testcontainers) e CI no GitHub Actions
- 🐳 Docker, PostgreSQL e migrações com Flyway
- 🔐 Spring Security, JWT e RBAC
- 📨 Processamento assíncrono com RabbitMQ, idempotência e DLQ
- 📊 Observabilidade com Prometheus e Grafana
